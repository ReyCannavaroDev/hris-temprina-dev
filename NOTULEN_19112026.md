# ROADMAP & DAFTAR TASK PENGERJAAN (URUTAN PRIORITAS KESULITAN)

## 🟢 KATEGORI MINOR (Mudah / Quick Wins - Fokus Frontend & Tampilan)
Tugas-tugas yang berisiko rendah, perubahannya terisolasi pada UI (Blade & JS), dan bisa diselesaikan dengan cepat.

- [x] **TASK-01: Master Posisi - Input Nama Jabatan Text Murni**
  - **Modul:** `Blades/m_posisi.blade.php`, `Javascript/m_posisi.js`
  - **Deskripsi:** Menghapus autocomplete dropdown/list `filteredOptions` di kolom input "Tuliskan Jabatan" agar murni menjadi form input text standar.
  - **Tingkat Kesulitan:** Minor (Sangat Mudah).

- [ ] **TASK-02: Jadwal Kerja Karyawan - Aktifkan Edit Detail Jadwal saat Create/Copy**
  - **Modul:** `Blades/t_jadwal_kerja_kary.blade.php`
  - **Deskripsi:** Mengubah atribut hardcoded `:bind="{ disabled: true }"` dan `:bind="{ readonly: true }"` pada baris tabel `detailArr` (`tipe_hari` KERJA/LIBUR, jam kerja) agar dinamis mengikuti status form (`:bind="{ disabled: !actionText }"`), sehingga user bisa switch hari libur saat Create maupun Copy.
  - **Tingkat Kesulitan:** Minor (Mudah).

- [ ] **TASK-03: Transaksi Cuti - Tampilkan Informasi Sisa Cuti Tahunan di Form**
  - **Modul:** `Blades/t_cuti.blade.php`, `Javascript/t_cuti.js`
  - **Deskripsi:** Menampilkan informasi sisa cuti tahunan karyawan (`m_kary.cuti_sisa_reguler`) pada form pengajuan cuti saat nama karyawan dipilih/saat user login membuat pengajuan.
  - **Tingkat Kesulitan:** Minor (Mudah).

## 🟡 KATEGORI MEDIUM (Sedang - Logika Bisnis, Relasi Data & Kalender)
Tugas-tugas yang membutuhkan ketelitian alur query, penyesuaian lifecycle status, dan pemetaan relasi antar tabel.

- [ ] **TASK-04: Master Posisi - Perbaikan Dropdown Divisi (Bug Hanya Tampil Manager)**

  - **Deskripsi:** Memperbaiki mapping data dan query scope pada dropdown divisi di form jabatan agar menampilkan seluruh daftar divisi yang valid, bukan hanya jabatan manajerial.
  - **Tingkat Kesulitan:** Medium (Sedang).

- [ ] **TASK-05: Master Karyawan - Pembatasan Filter Hierarki Atasan Langsung**
  - **Modul:** `Javascript/m_karyawan.js` (`fetchAtasanByDivisi`), `Models/m_kary/Custom.php`
  - **Deskripsi:** Menyesuaikan filter dropdown kandidat Atasan Langsung agar dibatasi ketat berdasarkan Company, SBU, dan SUB tempat karyawan berada (tidak menampilkan pejabat dari seluruh holding).
  - **Tingkat Kesulitan:** Medium (Sedang).

- [ ] **TASK-06: Transaksi Cuti - Auto-Calculate Pemotongan Sisa Cuti Karyawan saat Approved**
  - **Modul:** `Models/t_cuti/Custom.php`, `Models/m_kary/Custom.php`
  - **Deskripsi:** Mengimplementasikan kalkulasi otomatis pemotongan kuota `cuti_sisa_reguler` di master karyawan ketika transaksi cuti tahunan disetujui (`APPROVED`), serta penanganan pengembalian kuota jika dibatalkan/ditolak.
  - **Tingkat Kesulitan:** Medium (Sedang).

- [ ] **TASK-07: Laporan Absensi Karyawan - Indikator Khusus Hari Libur Nasional**
  - **Modul:** `Models/t_jadwal_kerja_n/Custom.php`, `Blades/web_report_karyawan_absensi_detail.blade.php`, `Javascript/l_karyawan_absensi.js`
  - **Deskripsi:** Mengintegrasikan data kalender `m_libur_nasional` ke dalam rekapitulasi laporan absensi agar hari libur nasional memiliki indikator/tanda visual khusus yang membedakannya dari libur jadwal rutin (hijau) dan mangkir/alpa (merah).

## 🔴 KATEGORI MAJOR (Kompleks - Arsitektur Scope Respo, Alter DB & Engine Presensi)
Tugas-tugas dengan dampak sistemik luas yang melibatkan hak akses multi-tenant, alter skema database, atau engine transaksi utama.

- [ ] **TASK-08: OS Karyawan - Filter Jangkauan Multi-Tenant Admin OS & Penanganan Data Kosong**
  - **Modul:** `Models/m_kary/Custom.php` (`scopeGetos`), `Cores/Respo.php`, `Blades/m_os_kary.blade.php`, `Javascript/m_os_kary.js`
  - **Deskripsi:** Mengatur izin akses data karyawan OS agar Admin OS hanya bisa melihat karyawan dalam 1 PT OS miliknya. Jika kolom PT OS pada karyawan masih kosong/null, data dibuka agar dapat dilihat & dilengkapi oleh semua Admin OS. Menyisir dan menyelaraskan modul respo yang belum memfilter PT OS.
  - **Tingkat Kesulitan:** Major (Tinggi / Kompleks).

- [ ] **TASK-09: Presensi Absensi - Snapshot Waktu Jam Kerja & Pemisahan Format Tanggal/Jam Lengkap**
  - **Modul:** `Models/presensi_absensi/Alter.php`, `Models/presensi_absensi/Custom.php` (`custom_checkin`, `custom_checkout`)
  - **Deskripsi:** 
    1. Melakukan alter database pada tabel `presensi_absensi` untuk kolom snapshot: `jam_kerja_in`, `jam_kerja_out`, `checkin_date`, dan `checkout_date`.
    2. Memperbarui engine checkin/checkout agar menyimpan waktu lengkap (tanggal + jam real masuk/keluar) dan menyalin snapshot jam kerja ke baris transaksi.
    3. Memastikan pembaruan ini kompatibel dengan generator dan tetap menjaga konsistensi laporan absensi yang saat ini mengacu pada jadwal kerja.
  - **Tingkat Kesulitan:** Major (Tinggi / Arsitektural).
